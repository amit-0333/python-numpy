## 📌 About

This is my **live NumPy learning journal** — the backbone of all Data Science and ML in Python.
Every concept I study gets uploaded here with notes, examples, and practice problems — from array creation all the way to vectorization, broadcasting, and real-world problem solving.

Built to master:
- Creating and manipulating NumPy arrays efficiently
- Indexing, slicing, reshaping & stacking arrays
- Mathematical operations, aggregations & linear algebra
- Advanced concepts — broadcasting, vectorization & ufuncs
- Applying NumPy to real-world Data Science scenarios
- Lesser-known NumPy tricks & shortcuts
